# YourFem · съдържание

> **In English.** The signed articles the YourFem app shows, and the manifest it reads
> them by. Published from the author's working folder by `tools/publish.mjs`; nothing
> here is edited by hand. All rights reserved — see [`LICENSE`](LICENSE).

Тук стоят **само подписаните статии** — тези с медицински рецензент, дата на прегледа
и неизтекъл срок. Черновите остават при автора. Хранилището е публично, защото
текстовете са публични така или иначе; пази се не тайна, а **кое е истинско**.

## Какво има вътре

| Файл | Какво е |
|---|---|
| [`manifest.json`](manifest.json) | Списъкът: коя статия е публикувана, с `sha256` на файла ѝ, и коя е **оттеглена** (`revoked`). Приложението вярва само на него. |
| `articles/<id>.json` | Една статия: заглавие, трите слоя (за нея, за студент, за лекар), източниците и подписът. |
| [`CHANGELOG.md`](CHANGELOG.md) | Какво е излязло при всяко публикуване. Пише го скриптът, не човек. |
| [`tools/publish.mjs`](tools/publish.mjs) | Портата от работната папка на автора дотук. |

Адресът, от който приложението чете: `https://yourfem.github.io/content/manifest.json`.

## Как се публикува

```bash
npm install
node tools/publish.mjs "<път до>/mvp/app/data/articles.json"
```

Скриптът **само чете** източника. Показва какво ще се промени и пита:

```
Нови: 2 · Променени: 1 · Оттеглени: 0 · Без промяна: 45
Публикувам? (д/н)
```

След „д“ записва статиите, манифеста и записа в `CHANGELOG.md`. Остават
`git add -A`, `git commit` и `git push`. С `--note "поправена доза желязо"` се добавя
**защо** — какво се е променило, скриптът знае сам.

## Трите правила на портата

1. **Минава само подписано.** Липсващ рецензент, дата или изтекъл преглед — статията
   остава при автора.
2. **Махната статия се оттегля, не се трие.** Влиза в `revoked` и изчезва от всеки
   телефон при следващата му проверка, включително от такъв, който е бил офлайн.
3. **Текст, променен без нов подпис, се задържа.** Излиза подписаната версия, а скриптът
   казва коя статия чака нов подпис. Промяна извън медицинския текст (например клъстер)
   минава нормално.

Тестовете: `npm test`.
